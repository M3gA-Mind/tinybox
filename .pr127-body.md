This stacked TinyBox #27 branch adds explicit loopback and metadata protection to allowlist validation and the opt-in native Linux Docker egress backend. Validation rejects loopback IP literals (including IPv4-mapped and scoped IPv6), localhost aliases, terminal DNS root dots as equivalent names, legacy numeric IPv4 spellings of loopback/metadata addresses, and loopback or cloud-metadata answers from the injected resolver. DNS resolution is performed once when planning an allowlist; the resulting IPs are retained in the plan.

The optional `NativeLinuxDockerEgressController` enforces pinned TCP destinations on a verified local, rootful Linux Docker Engine. It installs default-drop IPv4/IPv6 bridge firewall rules before workload start, checks that destinations do not overlap Docker-assigned bridge subnets, adds pinned `/etc/hosts` mappings, and disables upstream DNS forwarding for allowlist boxes. The input chain permits both IPv6 Neighbor Solicitation and Advertisement, plus established traffic needed for published-port replies. Its hosted live proof marks the sandbox's IPv6 neighbor entry stale on its managed bridge and repeats the allowlisted connection, exercising a fresh neighbor discovery exchange. Unsupported, remote, Docker Desktop, rootless, and unverifiable hosts remain refused. The default Docker sandbox still refuses allowlists unless this controller is explicitly installed. The real firewall proof runs only in disposable hosted Ubuntu Docker CI.

Firewall resources are scoped to a Docker network owner/scope/attempt label. Chain names include a 48-bit SHA-256-derived box identity plus a 48-bit attempt suffix within iptables' 28-character limit. If the network is already absent, the orphan scan uses the longer box-specific prefix so another box's chain cannot block cleanup. When the matching network still exists, cleanup can reclaim only an empty, unhooked chain from the matching attempt; nonempty or unverified chains remain untouched.

The regression test uses `default/box-0` and `default/box-1`, which collide on the previous four-hex prefix. It failed before the fix because cleanup refused while the other box's chain remained, and passes with the longer cryptographic identity. Existing restart recovery for an empty chain with its network present also passes. A deterministic TCP fixture confirms the published-port probe retries when the first connection closes cleanly before returning its response.

The module README documents non-interactive, passwordless `sudo` without `requiretty` for Docker, iptables, and ip6tables; it no longer lists unused restore tools as a prerequisite. The test timestamp uses `UNIX_EPOCH`, and the tracked compiler ICE dump was removed with future dumps ignored.
